## 0. 一页结论

- **五线收官(方案A / dose / mjitter×2轮 / rshell×2轮 / smask),四条随机化
  轴(方向/度量/剂量/时域)全部出局**。共同签名:要么被低秩 Jacobian 投影
  稀释,要么落 κ-平台被吸收,要么 κ 预算耗在参照系地板上,要么只在不重叠
  的可达场景间**重分配**——**没有任何一条臂解锁过 never-wall 场景(20 筛
  {4,6},mjitter 七跑未动;100 场景 ~20 个)中的哪怕一个**。
- **全 campaign 最锋利的因果证据 = mjitter r2 的校准解离**:κ 补偿把注入从
  0.084 精确修回工作带 0.92,救回纹丝不动(placebo 子集)——力的幅度满格、
  换了指向后增益全失 ⇒ **约束在方向质量,不在剂量**。方案三的价值 = 把 κ
  花在编码器高杠杆维;重定向(随机方向、旋转度量、时域重排)一律无增益或
  负增益。
- smask 三配置的救回并集恰 = 方案三全集 → "哪些场景救得回"由 DP 支持集覆盖
  决定,与预算的分配方式(方向/深度/时间)无关;分配只决定"拿到其中哪几个"。
- 在 cost 形式约束内**未被排除的机制只剩三个**:锚的条件化(failanchor)、
  σ 轴(J_σ 未探)、任务域(square)。smask 幸存价值 = 平滑红利
  (jerk 0.35→0.13-0.21),建议作 duty≥40% 叠加件而非独立线;mjitter b=0.5
  的 jerk −30% 同理(平滑 bonus,非多样性收益)。
- 20 场景筛对"比方案三好"的分辨力已近枯竭(运气占失败 33% vs 100 场景 15%,
  小筛平局证据弱),对"比 placebo 差"和机制指纹仍有分辨力。

## 1. 方案A — 均匀 κ-壳随机目标(死,三振)

**思路**:把 SOE"每 retry 一个随机行为假设"搬进 cost:每 (i,k) 采固定单位方向
u,目标后验 q* = N(μ⁰+√(2κ)σ⁰·u, σ⁰²)(恰在 κ 壳上),cost = KL(q_a‖q*) 为
二次势阱;N 个 retry = N 个不同倾斜分布各采一次,对阵方案三的"一个倾斜分布
采 N 次"。

**改动轮数**:η∈{0.115,0.35,0.7}(100 场景)+ 历史 κ∈1.25-5、η 26× 范围
扫描,共 ≥3 轮 → 三振。

**失败机制**:① 救回 10/13/12 vs 方案三 19;三档 η 的救回并集 14、净新增仅
1——随机目标连基线覆盖都收不回;② 剂量峰 pass@10 0.72 < 基线带 0.76-0.78;
③ η↑ 重试 PR↓(重试产出 1.56 vs 1.38 亦随 η 单调劣化):阱流 δ̇=−G(δ−δ*)
把横向分量以 λ_i 速率收回 G=JᵀΛ⁰J 谱顶锥——均匀 16 维方向经低秩 Jacobian
投影后,剩下的就是方案三自己加噪声。

**一句话经验**:在 cost 里采"编码器看得见"之外的方向是白采——方向多样性
先要过 im(Λ⁰^{1/2}J) 这道投影门;要在某空间采方向,先测那个空间的谱。

## 2. dose — 方案三 × 随机剂量(死,三配置)

**思路**:方向保持方案三(高增益锥),只随机剂量:每 retry 乘
w(i,k)~logU[w_lo,w_hi],N 个 retry 探 N 个深度。

**改动轮数**:(0.3,3)/(0.5,2)/(0.15,5) 三配置。

**失败机制**:前两组与基线救回**逐场景严格平**;(0.15,5) 严格子集(低尾掉
下剂量响应悬崖)。mean_inject = √(w_lo·w_hi) 精确成立:乘性剂量线性穿过,
而响应函数是"平顶 + 两侧悬崖"——平顶内换剂量不产生任何动作差异(随机性被
平台吸收),跨出平顶只有坏处。

**一句话经验**:先画剂量响应曲线再随机化剂量;响应是平顶时,随机剂量 = 零
收益 + 尾部纯风险。剂量轴的信息在响应的**边缘**,不在内部。

## 3. mjitter r1+r2 — 随机度量旋转(死,两轮七配置收官)

**思路**:不采方向,转而随机参考度量:每 retry 采 s=16·softmax(bξ),参考
精度 1/τ² = s/σ⁰²(Σs=16,总精度守恒的纯旋转);力恒为 JᵀΛ_k(μ−μ⁰) 型,
天然在 J 行空间,零投影回收;b=0 逐字节退化为方案三。

**改动轮数**:r1 = b∈{0.5,1,2,4};r2 = κ 补偿三配置(b=1+κ=6、
b=0.75+κ=4.6、b=0.5+SCALE3.6)。共七配置。

**失败机制**:① b=0.5 与基线严格平(吸收),但 jerk 低 30%——轻度度量旋转
无害但无增益(平滑 bonus,非多样性收益);② b≥1 死于**参照系地板**:
a=a⁰ 处 KL(q_a‖N(μ⁰,τ²)) = ½Σ[s−1−ln s] ≈ 3.75b² 已 > κ=2.5 →
min(KL,κ) 恒饱和 → clamp 梯度恒 0 → 注入≡0——b=2 因此成为"免费
placebo",反而产出了本 campaign 最有价值的对照数据(见 §7.1);③ **r2
决定性一击**:κ 补偿在机制层完全成功(3.75b² 公式验证、b=1 注入 0.084→
0.92 精确落回工作带),救回仍 = {9,18} placebo 子集——**注入恢复 ≠ 救回
恢复:同幅度的力换了指向,增益全失**,b=1 恶化的是力的方向质量(旋转把
逃逸力指向与救回无关的潜维);④ b=0.75+κ=4.6 与 b=0.5+SCALE3.6 均 4/6
平局,同 b 抬 SCALE 次线性(clamp 饱和,平台再现)——全局 η 买不回被
clamp 的 κ 预算;⑤ 七配置(b0.5-2.0、κ2.5-6、SCALE3-3.6)全落
{3,9,12,18} 或 placebo 子集,{4,6} 七跑未动。

**一句话经验**:把地板修好、把力喂饱,救回照样不回来——**方向质量才是
约束,不是剂量**;校准类度量(注入/剂量)只证明"力在工作",不证明"力
指向对的地方"。另:改任何参照先结算 KL(a⁰) 地板,κ 预算必须全花在位移上
(地板 ≥κ = 无声关机,不报错,只有日志知道)。

## 4. rshell r1+r2 — 可达子空间白化壳(死,两轮六配置;产出最重要的诊断)

**思路**:接受方案A的教训,把方向采进**实测可达子空间**:探针扰动 a⁰ → SVD
得 (V_r, λ),目标 μ* = μ⁰+√(2κ)σ⁰·û,û = normalize(V_r(λ̂^{−α}⊙ε))——投影
回收在原理上不可能。

**改动轮数**:r1 一轮 + r2(校准注入)一轮,共六配置(α×P×ε)。

**失败机制与产出**:① 全部配置 = placebo 指纹(救回 {9,18},与零注入逐位
相同);② **真谱**:顶部 2-3 维缓降 + 第 3 维悬崖,λ₃/λ₁≈0.10 跨 P 一致 →
方向多样性子空间上限 ≈3,几何上多样性本就没有空间;③ **主动抑制**(比吸收
更糟):校准注入下,在 placebo 易救场景上成功重试仅 2-4/10(方案三同场景
9+7)——把动作拉离 DP 意图、哪怕沿"编码器看得见"的方向,在 can rescue 上
净负价值;④ α 在可靠域无差异——但这组对比发生在整臂已无效的死配置之间,
只能读作"死配置内不敏感",不能外推为"维度分配无关"。

**一句话经验**:可达性解决"方向传得过去",不解决"方向值得去"——can rescue
的价值集中在唯一高杠杆维;子空间多样性上限由谱决定,谱在探针里免费,应该
最先看。

## 5. smask r1 — 随机时域门控(死,作为独立线;幸存为叠加件)

**思路**:方案三 cost 逐字节不动,只随机**何时**施加:chunk 级 0/1 调度
ω_k(c) 乘 cost。window 族(长 L 不重叠窗,L=8/4)、front 族(前 c0 引导后
释放,c0=16)。

**改动轮数**:三配置(window L=8 → {9,12,18} 3/6;window L=4 → {9,18} 2/6
= placebo 档;front c0=16 → {3,9,18} 3/6)。

**失败机制**:① **全部是基线严格子集、零新增、未碰 {4,6};三者并集恰 =
基线全集 {3,9,12,18}** → 门控只重分配可达场景(init3 需强/早引导,front 才
救回;init12 需持续引导,只有长窗 L=8 救回),不解锁新场景——时域轴作为
"解锁机制"关闭;② L=4 退到 placebo 档:预算摊薄到 1/10 duty 后引导密度
不够;③ 副产品:front 的释放段 jerk 0.35→0.13-0.21——guidance 的平滑代价
主要来自 episode 后段仍在推离意图。

**一句话经验**:改"何时花 κ"和改"往哪花 κ"一样,只是在可达集内部重新
发牌;"哪些场景可达"由 DP 支持集决定,不由分配决定。时域门控的正确用法是
叠加件(duty≥40% 保底 + front 释放换平滑),不是独立探索线。

## 6. 跨线规律(对已成形假设的检验)

**假设原文**:随机化的力要么被噪声尾稀释、要么被 κ 预算挤死、要么落剂量
平台 → κ 封顶 + DP 先验双信任域对"重新定向"类随机性有强吸收;"离开意图"
对 can rescue 本身负价值,方案三赢在把 κ 花在唯一高杠杆维 → 任何方向/度量/
剂量随机化在 can 上无上行空间,多样性的期望收益只在"何时引导"(smask)或
换任务(square)。

**判定:主体支持;两处表述需修正;一个推论已过时(smask 也死了)。**

支持(逐条):
- "强吸收"多线一致:方案A(投影稀释:并集 14 vs 19、净新 1)、dose(平台
  吸收:严格平)、mjitter b=0.5(度量旋转吸收:严格平)。共同根源 = 引导
  分布 p_DP·exp(min(KL,κ)) 只是对 DP 质量的 ≤e^κ≈12× 重加权,κ 又被 1/σ⁰²
  马氏加权集中花在高增益维——小预算重加权对零均值扰动天然稳健。
- "吸收"须拆成三个机制不同的子类(共用 κ·e^κ 小预算这个根源):投影回收
  稀释(方案A)/ 平台吸收(dose、mjitter b=0.5)/ 预算饿死(mjitter b≥1 的
  KL 地板)。
- "离开意图负价值":rshell 的主动抑制(2-4/10 vs 9+7)是直接证据。
- smask 落地后,原推论的两个"期望收益出口"之一(smask)已证伪为独立解锁
  机制:**四条轴(方向/度量/剂量/时域)没有任何一条解锁过 never-wall 场景**;
  smask 的并集=基线全集进一步支持"可达集由支持集覆盖决定"。

需修正的两处:
1. "离开意图负价值"要加方向限定:方案三自己也在离开意图(boost 在 κ 壳上
   最大),且它赢。准确表述:**向编码器高增益方向离开意图 = 正价值;向低
   杠杆/随机方向离开意图 = 负价值**。rshell 的目标虽在可达子空间内(行为
   可见),但"行为可见"≠"救援有价值"。
2. "方案三赢在唯一高杠杆维"原本缺直接消融(rshell 的 α 无差异是在死配置
   之间测得的,不构成"维度分配不重要"的证据);**mjitter r2 补上了活体
   证据**:κ 补偿后注入与方案三同处工作带(0.92),唯一系统性差异 = 参考
   度量旋转 → 救回跌回 placebo——同幅度、异指向 = 增益全失。严格说它证明
   的是"指向敏感"而非"恰好 top-1 维"(旋转同时改变维度分配与逐 retry
   一致性),但已把论断从旁证(谱 λ₁ 主导 + 方案三的力沿局部 KL 最速方向
   自动落 G 谱顶)升级为直接证据。

推论的现状:
"任何方向/度量/剂量随机化在 can 无上行空间"——mjitter r2 收官后,该论断
在**零漂移、对称**随机化子族内五线全部成立(全部死线 E[目标]=μ⁰、
E[剂量]=1、E[度量]=I,均值回中;度量轴连 κ 补偿修满注入后仍 placebo),
且时域轴(smask)同样只重分配、不解锁。两个漏洞仍未关:
- **条件化/非对称随机**(锚在已失败行为、按结果反馈)——不是"重新定向",
  是"定向逃离已证伪方向",五条线全部未触及;
- **σ 轴**:所有死线只碰了 KL 的均值项;σ 头的 Jacobian J_σ 从未探测
  (mjitter 的 τ² 随机化也只经参考间接碰,且其死因在均值项方向质量)。
"多样性收益只在 smask 或 square"的两个出口中,smask 已证伪为独立解锁
机制;剩 square 未测、锚/σ 未测。

**还缺的实验(按信息/成本比排序)**:

   never-wall 上的理论上限(重加权造不出 DP 没有的质量)。
2. **J_σ 谱离线探针**(零 GPU,一次编码器前向,rshell 探针协议改 logvar
   输出):决定 σ 轴生死,门控提案 3。
3. **square 复制筛**(提案 2):检验死线结论的跨任务外部效度。
4. (方法学)**重试多样性指标缺位**:RUNBOOK 优化目标写着重试多样性,判读
   协议却只读救回/pass@10——dose/mjitter-b0.5 的"严格平"在多样性轴上是

   注:100 场景 placebo 锚已由 coordinator 补齐(6/39),不再缺;若后续要

## 7. 方法论经验

1. **placebo 对照不是可选项**:mjitter b2 的意外零注入免费产出了因果分解
   ——方案三 4 个救回里 2 个是重试运气。没有它,"dose 严格平"会被读成
   "dose 一样好"而非"两边都没赢过运气"。每个新臂要么带 scale=0 对照,
   要么带一个可证明注入≡0 的配置。
2. **运气占比校准平局带**:20 场景筛失败中运气占 2/6=33%,100 场景仅
   6/39≈15%——小筛过采样"边界型失败"(DP 决策边界附近,重采样就能翻),
   平局在小筛上是弱证据。判读主指标应是**救回集合的结构**(严格子集/
   并集/指纹逐位相等),其次才是计数;小筛平局 → 上 100 场景再定生死。
3. **谱预诊断先行**:rshell 探针(顺带、免费)给出的 r≈2-3 与 λ₃/λ₁≈0.10
   比任何 GPU 筛查都值钱——它在烧卡前就封了方向多样性的天花板。凡在某个
   子空间采样的臂,必须先打印该子空间的谱。
4. **κ 预算记账**:改任何参照(度量/目标/方差)先算 KL(a⁰) 地板;预算必须
   全部花在位移上。地板 ≥κ = 无声关机(b2 那种"注入恒 0"要靠日志发现,
   不靠报错)。
5. **mean_inject 的幸存者偏差**:mean_inject≈1.0 的"工作点"是在活臂上标定
   的;均值掩盖双峰(一半恒 0、一半爆表也能均值 1)。判读应报注入**分布**
   (clamp 命中率、零注入占比),不只报均值;mean_inject=√(w_lo·w_hi) 的
   精确成立说明它只是剂量的线性回声,不是效应量的度量。
6. **注入恢复 ≠ 效应恢复(r2 的校准解离)**:κ 补偿把注入 0.084→0.92 精确
   修回工作带,救回纹丝不动——校准类度量(注入分布、剂量、公式验证)只
   证明"力在工作",不证明"力指向对的地方";机制验证通过后,效应判定必须
   回到救回结构。同 b 抬 SCALE 次线性(clamp 饱和)再次提醒:全局 η 买不
   回 κ-clamp 掉的预算。
7. **byte-exact 退化锚**:每臂带一个可证明逐字节退化为方案三的旋钮
   (b=0 / w=1 / ω=1),是免费的回归测试 + 指纹比对的基准零点。
8. **确定性播种使指纹比对成为可能**:(rand_seed,i,k) 播种让"救回集合逐位
   相等"成为可读信号(placebo 指纹就是这么发现的)——保持这个约定。
9. **串行化代价要预算**:结果条件化(锚/反馈)需要 job gate 串行化重试,
   rollout 变慢 ~2×;并行完成序≠尝试序,设计时先想清楚锚的时序语义。
10. **平滑是可采购的副产品**:front 门控把 jerk 0.35→0.13-0.21,mjitter
    b=0.5 再降 30%——guidance 的平滑代价集中在 episode 后段与高增益维的
    连续推动。若后续任何臂过线,叠加 duty≥40% 的 front 门控可白拿平滑,
    不再单独开线。

## 8. 新方向提案(准入:KL cost 形式不动 / dyn 不动 / 随机性在 cost 内 /
部件最小化 + 理论依据)

> 与已收官线的关系:五线收官后无在途臂;smask 与 mjitter b=0.5 均降级为
> 叠加件(duty≥40% 门控 / 平滑 bonus)。三案互斥可并行评估;failanchor
> 过线后可与门控叠加件复合(锚 × front 释放)。

### 提案 1|failanchor — 失败锚定参考(can 内唯一未测机制,主推)

- **数学一句话**:C_k = −min(KL(q(z|s̄,a) ‖ N(μ̄_fail(i,k), σ⁰²_k)), κ),
  其中 μ̄_fail = 本场景**已完成失败重试**意图后验的截尾均值(或就取 retry 0
  首块意图;成功重试不入锚);retry 0 保持方案三;力 = JᵀΛ(μ−μ̄_fail),
  仍在 J 行空间,零投影回收。可选护栏:锚位移截断在 √κ 壳内(保证 KL(a⁰)
  地板 ≤κ/2,呼应 §7.4 记账)。
- **随机性在哪**:锚由已实现的重试随机性决定——cost 消费随机性、不新造
  噪声源;参照系替换属 RUNBOOK 允许的"参考/目标方向"类注入。
- **部件数**:2(+1 可选护栏)—— 锚缓存(直接复用 NoveltyCostPlanner 的
  on_try_done/encode_executed + job gate 管线)+ 截尾分位数(先固定 0.2
  不扫)。
- **理论依据**:① 方案三推导 Step 4 要求参照系 = "策略会做的";rescue 语境
  里**已知**的策略行为是已失败的那些,不是本 retry 的新采样——锚定失败才是
  推导在 rescue 语境的正确实例化(entropy_cost.md §1 的原始动机"直接重采样
  等价于重复同类失败"说的正是这个,但现行实现的参照系随重试抖动);②
  placebo 分解:{9,18} = DP 自身散布够 → 那里 μ̄_fail≈μ⁰,锚定自动退化为
  方案三(回归安全);{4,6} never-wall = "重试重复失败"的候选反例 → 反失败
  漂移恰在全部死线未覆盖处发力;③ rshell + mjitter-r2 教训:方向仍由编码器
  几何选定(不采样、不旋转)——r2 刚证明同幅度换指向 = 增益全失,而
  failanchor 保留方案三的几何选向、只换锚点,恰是五条线都没碰过的变量;
  ④ 这是 SOE rescue 本质(围绕失败行为扰动)在 cost 形式下的最小实现,
  比 ShellWalk 省掉方向采样部件。
- **赌的机制**:锚的条件化/不对称(M-A)+ 重试相关性——四条死线全是零漂移
  对称随机化,锚从未被动过。
- **要扫的参数**:锚模式 {retry0-only, trailing-mean} 两点;q=0.2 固定;
  κ=2.5、η 取基线工作点单点。
- **预测失败模式**:① never-wall 若是"支持集饿死"(重试本已多样)→ 无效,
  退化为 tie——先用 §6 缺实验 1 的离线诊断一轮前否决(零成本);② 方案二
  血统风险:NoveltyCostPlanner 当年被弃(记录原因:多样性只来自演化缓存),
  它没被三振、也未在本协议与方案三同场对比过——上臂前先查旧数字;③ 锚过期
  (轨迹发散后早期锚失去意义)→ 若 tie 再考虑 chunk 对齐锚(部件+1);
  ④ job gate 串行化拖慢筛查 ~2×。**诚实的先验**:解锁 {4,6} 的概率低
  (四条轴都没碰动过它们);本提案的主要价值 = 重试多样性(RUNBOOK 明写的
  优化目标,递归/尾均锚让 10 次重试变成"失败模式空间的粗搜索")+ 机制
  完备性(cost 形式内最后一个未测轴)。
- **判读注意**:因 §7.2 的运气占比,本臂生死必须看集合结构 + 100 场景确认,
  不以 20 筛计数定。

### 提案 2|square 复制筛(战略选项,0 新部件)

- **数学一句话**:无新 cost;在 square 20 场景筛上跑三臂——方案三 /
  placebo(scale=0)/ rshell(死臂),读三个数:placebo 救回数、方案三救回
  数、rshell 相对 placebo 的符号。
- **部件数**:0(square base DP + dyn-base ckpt 早期 campaign 已有;
  rand_screen.sh 数据路径 ~1 个开关)。
- **理论依据**:can 的失败结构已被证明"支持集覆盖型"为主(四种子 probe:
  探索失败 86% 冗余;本筛 2/6 重试可救;100 场景运气 15%)→"离开意图
  负价值"可能是 can 特例;square base SR≈0.37-0.40,失败模式更多样、rescue
  价值空间更大——那里才是这个方法该赢的地方。
- **赌的机制**:跨任务外部效度(M-task)——检验死线结论的条件性,不赌单一
  机制。
- **要扫的参数**:无;一轮 20 场景筛 ×3 臂。
- **预测失败模式**:square 签名与 can 相同(placebo 分数同样高、rshell 同样
  抑制)→ 死线结论升级为一般规律,campaign 应收缩到 failanchor 或与用户
  重谈停止条件;另:square 单轮更贵(500 步、模型更大),筛查 ~2-3× 时间。

### 提案 3|σ-谱探针,门控后的 entropyseek 瘦身版

- **数学一句话**:先零成本离线探 J_σ = ∂logvar/∂a 的谱(rshell 探针协议换
  logvar 输出);仅当谱非平凡(秩 ≥2、增益轴与 J_μ 不同)才上 cost 附加项
  −min(Σ_i m_{k,i}·[ln(σ_i/σ⁰_i)]₊, κ_σ),m 为 (i,k) 播种的随机掩码。
- **部件数**:探针 0;cost 版 2(掩码密度 ρ、κ_σ)。
- **理论依据**:KL 的 σ 项(σ²/σ⁰²−1−ln·)在全部死线里被显式钉死(方案A/
  rshell 的目标方差 = σ⁰²,σ-escape 关闭),σ 头是编码器输出里唯一未被任何
  臂触碰的张量轴;DIAYN 对偶:判别不确定(σ 大)= 行为摘要未承诺 = 未探索。
- **赌的机制**:σ 轴独立性(M-V)——J_σ 与 J_μ 是否不同秩、不同轴,从未测。
- **要扫的参数**:门控在探针;过关后 ρ∈{0.25,0.5}、κ_σ∈{1.25,2.5}。
- **预测失败模式**:最可能——J_σ 增益 ≪ J_μ(VIB 训练目标从不奖励 σ 对 a
  的敏感度,σ 大体由 s̄ 决定)→ 梯度被吸收、tie;这正是探针先行(零 GPU)
  的理由,预期是否决而非放行。

### 停止条件的算术(供决策,不是提案)

100 场景:失败 39,placebo ~6,方案三 19(引导净增 ~13),never-wall ~20。
停止条件 pass@10>0.85 需救回 ≥24 → 比最好轮 +5,即从 never-wall 的 20 个里
再挖 ≥25%。四条轴全部没能从 never-wall 挪动一个场景;若缺实验 1 判定
never-wall 是"支持集饿死",则 cost 族在此约束下**原理上够不到 0.85**,
应尽早把证据摆给用户、谈停止条件或换测试床(square),而不是继续烧臂。
