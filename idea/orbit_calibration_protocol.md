# orbit 标度协议:跨任务免标定与无 pass@10 直接标定(方案稿,2026-09-02)

> 状态:方案待用户审。数据支撑 = SQUARE 08-31 标定 + CAN 09-02 标定(4 组 σ 在跑)。
> 目标(用户原话):(1) 参数在不同任务上无需标定;(2) 有指标可以根据采样的一批数据直接标定,不需 pass@10 实验(pass@10 对真机不可行)。最终目标 = robustness。

## 0. 问题:orbit 的五个旋钮,哪些吃任务尺度

orbit 注入(per guided denoise step,trajectory a,梯度 ∇f = ∇_a KL(q(z|s,a)‖q(z|s,a⁰))):

- phase-1(爬坡,f=KL < κ−δ):注入 η·√(1−ᾱ_t)·(−∇f) —— 与 atypical 逐字一致。
- phase-2(壳上,f ≥ κ−δ):Newton 反馈 −λ·(f−κ)/‖∇f‖²·∇f + 切向噪声 σ·√(1−ᾱ_t)·ξ⊥。

| 旋钮 | 现值(square 定标) | 单位 | 跨任务变化来源 |
|---|---|---|---|
| η | 3.0 | 位移/梯度 | **吃 VIB 梯度尺度** ‖∇f‖(实测 can=square 的 7–43×) |
| κ | 2.5 | nats | 意图后验 KL 分布的位置/形状随任务变 |
| δ | 0.25 | nats | 同 κ |
| λ | 0.5 | 无量纲(反馈增益) | 无(设计上已免换算) |
| σ | 0.25 | **动作位移** | 动作空间物理尺度(robomimic 内相近;真机会差) |

结论:**需要处理的只有 η(梯度尺度)、κ/δ(KL 分布位置)、σ(动作尺度)**;λ 天然免标。

## 1. 为什么 pass@10 不是好标尺(动机链)

1. **小样本排序不稳定**:SQUARE 6 场景探针给出 救回 σ0.5(5)>σ0.25(3)>σ0.1(4),62 场景定集反转 为 σ0.25(36)>σ0.50(32)。6 场景的 pass@10 排序在定集上不保序——离散成败信号在小 N 下噪声 > 效应。
2. **真机不可行**:pass@10 需要 env 的成功判定与 10 次重置,真机上每次判定都要人/视觉系统在场。
3. **标定一次不等于全程对**:同一链不同轮(VIB 重训)梯度尺度漂移(entropy campaign e2 |dNLL/da| 9→109),静态标定在链上会过期。

因此标准必须是:**连续量、每步可算、不依赖成功信号、对参数单调(或单峰)**。

## 2. 方案(1):无量纲化——让 square 定出的数直接搬到新任务

原则:每个旋钮除以它所吃尺度的任务内测量值,把"绝对值"变成"相对值"。

- **η̃(梯度归一)**:注入改为 η̃·√(1−ᾱ_t)·∇f/‖∇f‖_med,‖∇f‖_med = 同 batch 各行 ‖∇f‖ 的中位数。
  语义:每步注入固定大小的动作位移(相对批次典型梯度),而非固定倍数的梯度。
  实证支撑:exploit campaign 的 η=250×g_sq/g_can 线性换算恢复 = 尺度律成立,归一化是其自动化。
  代价:phase-1 与 atypical 不再逐字节一致(协议变化);失去"梯度大推得猛"的自适应(反正 η 本来就要重标)。
- **σ(动作尺度归一)**:σ = β·√(1−ᾱ_t)·s_a,s_a = core 数据动作维 std(部署前一次统计)。
  语义:噪声 = 策略动作自身尺度的 β 倍。β 无量纲。
  实证检验(本次 can 标定即做):β_can = σ*_can/s_a,can 对照 β_sq = 0.25/s_a,sq。**若两任务甜点的 β 对齐(同量级),方案获得第一个实证;若不对齐,说明 σ 还吃别的任务量(如 KL 地形曲率),退回方案(2)。**
- **κ/δ(KL 分位数定义)**:κ = p90{KL(q(z|s,a)‖q(z|s,a⁰)) : (s,a)∈core},δ = 0.1·κ。
  语义:"让 10% 的示教行为算 atypical"。分位数定义消灭单位,跨任务自洽。
  检验:square core 的 p90 是否 ≈2.5(现值)。若远偏,说明 2.5 只是恰好,分位数定义更 principled。
- **λ**:不动。

**可证伪预测**:按此协议,can 上直接取 square 的 (η̃, β, κ-p90, λ=0.5) 应落在 can 手动标定甜点的邻域。can 4 组 σ 结果出来即可算第一笔账。

## 3. 方案(2):采样数据直接标定——两阶段协议,全程无 pass@10

分"部署前(离线,demo 数据)"与"上线后(首批遥测)"两段,全部只需要模型前向/反向与动作序列,**不需要成功信号**:

### 阶段 0(部署前,core/demo 数据上,一次)
- **VIB 梯度探针**:批量 (s,a) 前向+反传,测 ‖∇f‖ 分布(中位数 g̃)。η ← η*/g̃,η* 为跨任务常数(square+can 标定数据联合拟合)。已在 tool_hang 实操过人工版(scale=12 即由探针外推,实测 mean_inject 1.27 落带)。
- **KL 分布探针**:同批数据测 KL 分布 → κ ← p90。
- **动作尺度统计**:s_a ← demo 动作 std → σ ← β·s_a。

### 阶段 1(上线,首批 20–50 个 guided chunk 的遥测)
三指标对带(带由 square/can 标定数据拟合),偏则乘法修正一步:
1. **mean_inject**(η·√(1−ᾱ)·‖∇f‖ 的实测均值)——总剂量。square 链带 ~0.6–0.8,tool_hang 1.27 落带,can 待定。修正:η ← η·target/current。
2. **phase-2 占比** p2_rows/calls——壳约束工作点。square σ0.25 ≈48%(健康);过高 = κ 太易够到或爬坡过猛(can_orbchain r1 现值 71% = 偏热信号);过低 = 够不到壳,orbit 退化成 atypical。目标带 ~[40%,60%](can 数据出来后校准)。
3. **KL 贴壳度**:median(KL)/κ ≈ 1 且 P(KL>κ+δ) 小——壳约束满足度的直接读数,纯模型量。

### 阶段 1.5(几何指标,补强,需要一批重试轨迹但不需成功判定)
4. **PR(轨迹发散比)**:20 条重试轨迹动作序列两两距/基准。宽度目标的直接测量(square:orbit σ0.25 PR 1.38 > atypical 1.28)。
5. **jerk**:动作二阶差分。过剂量早期签名;注意按方法分层带(orbit 本身比 atypical 高:square 0.47 vs 0.27)。

### 为什么带可以跨任务
带拟合的不是绝对 pass@10,而是"机制工作点":mean_inject 是注入的物理量(动作位移/步),p2/KL-κ 是约束满足度——它们的"健康区间"由 orbit 的数学结构决定(壳要贴、爬坡别过冲),不由任务决定。任务只改变参数到工作点的映射,不改变工作点本身。**这正是 robustness 的来源:固定工作点,让参数随任务自动伸缩。**

## 4. 验证计划(用本次 can 标定做第一轮检验)

| 检验 | 数据 | 判据 |
|---|---|---|
| β 对齐(方案 1 的 σ 部分) | can 4 组 σ 的 pass@10 甜点 σ*_can | β_can = σ*/s_a,can vs β_sq 同量级 |
| 带跨任务稳定(方案 2) | 4 组的 mean_inject / p2 / jerk | 甜点组的指标值落在 square 带内 |
| 指标可代 pass@10(方案 2 核心) | 4 组的 (指标, pass@10) | 单调/单峰同调:指标排序 = 性能排序 |
| κ-p90 定义回验 | square/can core KL 分布 | p90 与现用手调 κ(2.5)的偏差 |

任一检验失败都有明确退路:β 不对齐 → σ 进方案(2) 的带标定;带不稳 → 加任务维度(动 g̃ 探针)。
