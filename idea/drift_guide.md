# Drifting Policy 的 Classifier Guidance(保持 1-NFE)

> 2026-09-09。推导:ZCode;两轮 subagent 负向审查(迭代 1 FAIL:P0×1+P1×3;迭代 2 PASS,全部定理经数值抽查存活)。
> 语境:Drifting Model(Generative Modeling via Drifting,arXiv:2602.04770)把生成迭代搬进训练期,推理 = 一次前向(1-NFE)。本文回答:**使用时如何在 1-NFE 下给 drifting policy 加 classifier guidance**。
> 论文本身只有 classifier-**free** guidance(§3.5/A.7,CFG 训练期化);本文是它的 classifier 版对位物。

## 0. 设定与记账约定

- 冻结 drifting 策略 f_θ: R^n×O→R^D,种子 ε~γ:=N(0,I_n),一次使用 = 一次前向 x=f_θ(ε,o)。
- 输出律 q_o:=(f_o)_#γ(f_o:=f_θ(·,o)):q_o(B)=γ(f_o⁻¹(B))。
- 代价 C: R^D×O→R 可微有界,|C|≤κ(SCOUT 实例 C=−min(KL,κ)∈[−κ,0],单边封顶)。
- **Classifier guidance 的目标 = 指数倾斜律**:
  q_o^C(dx) := e^{−C(x,o)}·q_o(dx)/Z(o), Z(o)=∫e^{−C}dq_o>0。
- **NFE 记账**:只数生成器 f_θ 求值;代价网络(classifier/VIB)前向/反向不计(ADM 惯例:分类器梯度不占 NFE)。

## 1. 定理 1(引导 = 种子重加权,严格恒等)

**γ̃_o(dε) := e^{−C(f_o(ε),o)}γ(dε)/Z(o) ⟹ (f_o)_#γ̃_o = q_o^C。**

证:任取有界 Borel 检验 φ,
∫φ d[(f_o)#γ̃_o] = ∫φ(f_o(ε))e^{−C(f_o(ε),o)}/Z·γ(dε) = ∫φ(x)e^{−C(x,o)}/Z·q_o(dx) = ∫φ dq_o^C,
第二步取 u(x)=φ(x)e^{−C(x,o)}(有界可测:φ 有界、e^{−C} 有界、C 连续),用像测度定义。∎

推论:
- (i) **零近似**:不需 f 可逆、无 Jacobian——测度重加权,不是传输。
- (ii) **支撑不变**:dq^C/dq=e^{−C}/Z 处处有限正 ⟹ 互通绝对连续、支撑相同:guidance 只重分配质量、不外延支撑(h-变换保零测定理的同款自限性)。
- (iii) 见引理 1。
- (iv) 精确采样两形态:**拒绝采样**(提议 ε~γ、按 e^{−C}/e^{κ} 接受)精确但次数随机,期望 e^{κ}/Z∈[1,e^{2κ}](单边封顶下 [1,e^{κ}]≈12);**best-of-N**(固定 N、输出 argmin C)次数固定但输出律是 argmin 次序统计量 ≠ q^C(N→∞ 集中到 C 极小点集)。SCOUT rescue×N 对成功事件属拒绝采样形态(精确条件化,随机接受)。

## 2. 引理 1(κ 封顶的分布效应)

(a) |C|≤κ ⟹ TV(q_o^C,q_o) ≤ **tanh(κ/2)**(κ=2.5 时 ≤0.848);
(b) 单边 C∈[−κ,0] ⟹ TV ≤ **tanh(κ/4)**(κ=2.5 时 ≤0.554,界紧),且逐点密度比 d q^C/dq ∈ [e^{−κ}, e^{κ}](放大 ≤12.2 倍;上界为 sup 而非可达值)。

证:记 w:=e^{−C}∈[a,b],E_q[w]=Z,TV=(1/2Z)E|w−Z|。固定 Z,E|w−Z| 关于 w 的律是凸泛函;可行集(支撑⊂[a,b]、均值 Z)的极点为至多两点支撑律(Bauer);两点律 {u,v}(u≤Z≤v)处 E|w−Z|=2(Z−u)(v−Z)/(v−u),对 u 偏导 −2(v−Z)²/(v−u)²<0、对 v 偏导 +2(Z−u)²/(v−u)²>0 ⟹ 最大在 u=a、v=b ⟹
TV ≤ g(Z):=(Z−a)(b−Z)/(Z(b−a));
g(a⁺)=g(b⁻)=0,g′=0 有唯一驻点 Z=√(ab) ⟹ 驻点即最大值。
(a) a=e^{−κ},b=e^{κ}:g(√(ab))=(1−a)/(1+a)=tanh(κ/2)。
(b) a=1,b=e^{κ}:g(√b)=(√b−1)/(√b+1)=tanh(κ/4);逐点比:w∈[1,e^{κ}]、Z≥1 ⟹ w/Z≤e^{κ},w/Z≥1/Z≥e^{−κ}。∎

**语义:κ 封顶限制的是逐点质量放大倍数(≤e^{κ}),不保证分布形状相近(单边 TV 可达 0.55)——不支持「引导后分布仍接近原策略」的解读。**

## 3. 命题 2(倾斜种子律的精确 score;排除项)

C(·,o)∈C¹、f_o∈C¹ ⟹ γ̃_o 的 Lebesgue 密度(γ̃≪Leb:γ 正密度 × 正连续 RN 导数)满足

**∇_ε log γ̃_o(ε) = −ε − J_{f_o}(ε)ᵀ∇_xC(f_o(ε),o)**

(一次 f 前向 + 一次 VJP 可得:高斯 score + 链式法则)。种子 Langevin 用它作漂移需 K+1 次生成器求值,**违反 1-NFE,排除**;其地位是精确性锚点。∎

## 4. 定理 3(使用时单步引导:严格 1-NFE 方案)

**配方:ε~γ;x = f_θ(ε,o)(唯一生成器求值);â := x − η·Σ_o·∇_xC(x,o);输出 â。**
Σ_o≻0 为固定预条件子(只依赖 o,离线估计;谱范数 s)。

- **3.1(NFE)**:生成器求值次数 = 1;∇_xC 仅需代价网络反向。∎
- **3.2(高斯-仿射精确)**:q_o=N(μ,Σ)、C(x,o)=c₀+cᵀx、Σ_o=Σ、η=1 ⟹ Law(â)=q_o^C **精确**。
  证:配方 −½(x−μ)ᵀΣ⁻¹(x−μ)−cᵀx = −½(x−(μ−Σc))ᵀΣ⁻¹(x−(μ−Σc))+const ⟹ q^C=N(μ−Σc,Σ);â=x−Σc 是确定性平移 ⟹ Law(â)=N(μ−Σc,Σ)。∎
  (设计原则:协方差预条件;λI 是各向同性退化。)
- **3.3(良设性与诱导律)**:C(·,o)∈C²、∇C 为 L-Lipschitz、ηsL<1 ⟹ G(x):=x−ηΣ_o∇C(x,o) 是 R^D→R^D 的 C¹ 微分同胚。
  证:单射 ⟨G(x)−G(y),x−y⟩≥(1−ηsL)‖x−y‖²>0;真性 ‖G(x)‖≥(1−ηsL)‖x‖−const→∞;局部微分同胚:Σ_o∇²C 相似于对称阵 Σ_o^{1/2}∇²CΣ_o^{1/2},特征值模 ≤sL<1/η ⟹ det DG>0;Hadamard–Caccioppoli。q_o≪Leb(如 n≥D 且 J 满秩 a.e.)时 Law(â)=G#q_o 有密度 ρ̂(y)=q̃(G⁻¹(y))|det DG(G⁻¹(y))|⁻¹。∎
- **3.4(一阶一致及范围)**:加假设 ‖∇C(·,o)‖≤G。q_o=N(μ,Σ)、Σ_o=Σ、φ∈C²_b:
  E[φ(â)] = E_q[φ] − η·E_q[∇φᵀΣ∇C] + O(η²)(余项需 E‖∇C‖²<∞,由 G 界保证);
  E_{q^{gC}}[φ] = E_q[φ] − g·Cov_q(φ,C) + O(g²)。
  高斯分部积分 0=∫∇·(φw q̃) ⟹ E[∇φᵀw]=E[φ(−∇·w+wᵀΣ⁻¹(x−μ))];取 w=Σ∇C:
  E[∇φᵀΣ∇C] = E[φ(∇Cᵀ(x−μ) − Σ:∇²C)]。
  C 仿射时 = Cov(φ,C) ⟹ η=g 一阶严格吻合(3.2 的微分版本);一般 C 偏差由曲率项 Σ:∇²C 与非仿射项显式给出。
  **结论:单步 kick 是倾斜的一阶代理,仿射-高斯下精确;精确倾斜需多步+噪声注入(被 1-NFE 排除)。**∎
- **3.5(信任域)**:‖â−x‖ ≤ η·s·G:位移显式有界;STE「封值不封梯度」实现下 G 按实测梯度分位校准。∎
- **3.6(支撑注记)**:kick 的支撑 = G(supp q_o),一般不同于 supp q_o;满支撑情形集合不变、变的是测度分配,真子集/低维像集情形输出可离开像集。**支撑不变是种子倾斜(定理 1)的性质,kick 不是倾斜的精确实现——安全性由信任域+动作限幅保证,不由封顶传递。**∎

## 5. 定理 4(引导条件化:训练期摊销,使用时 1-NFE)

场定义:V_{p,q}(x)=E_{y⁺~p,y⁻~q}[k̃(x,y⁺)k̃(x,y⁻)(y⁺−y⁻)],k̃=距离归一化核(论文 Eq.11/Alg.2)。

配方:扩展 f_θ(ε,o,g),g∈[0,g_max](复用论文 CFG 的 α 条件槽);训练正样本按倾斜律抽
y⁺ ~ p̃_o^{(g)}(dy) ∝ e^{−gC(y,o)}·p_data(dy|o)(离线算好权重);
g 采样仿论文 α 表(如 50% 质量 g=0、其余 p(g)∝g^{−3});场形式不变 V_{p̃,q}=V⁺_{p̃}−V⁻_q。

- **4.1(反对称性保持)**:总体场上 V_{q,p}=−V_{p,q}(交换 y⁺↔y⁻ 差向量反号、归一化因子乘积不变、Fubini)——性质只依赖核形式,与 p 换成 p̃ 无关 ⟹ q=p̃ 时 V≡0:**平衡点 = 倾斜目标律**。批级实现下论文 A.1 论证 V_{p,p}=0 仍成立(平衡所需性质)。∎
- **4.2(可识别性)**:论文 C.1 的双线性约束论证只依赖反对称结构,对 (p̃,q) 逐字适用(承论文假设,非新增证明)。∎
- **4.3(使用时与两侧关系)**:给定 g 一次前向,NFE=1;g=0 退化无引导,g 连续插值倾斜强度。**两侧重合仅在理想极限**:q_o=p_data 且 g=1 时,e^{−C}p_data 归一化 = q^C;一般情形训练期目标是 e^{−gC}p_data(≠q^C),偏差由 drifting 可识别性(承论文假设)+训练误差共同决定;「推理期零近似」仅对 f 学到的分布成立,不对 q^C 成立。论文 CFG Eq.15–16 是训练期路径的线性组合特例。∎

## 6. 落地注记(SCOUT 实例化)

1. **a⁰ 参照必须独立于被扰动求值点**:若 a⁰=x(同种子未引导输出),则 C(x)=KL(q(z|s̄,x)‖q(z|s̄,x))=0 且 x 为全局最小 ⟹ ∇C(x)=0,kick 恒零失效。正确做法:a⁰=a⁰(o) 显式离线构造(如 E_γ[f(ε,o)]);drifting 下每 chunk 单次生成、无块内 a⁰ 漂移问题,但也没有「捕获 a⁰」的钩子,必须离线提供。
2. κ 封顶直通(封值不封梯度);G(梯度界)按实测分位校准。
3. 并发批逐样本归约(sum 非 mean)——1/B 教训。
4. η 剂量单位从「逐步 ×√(1−ᾱ_t)×100 步」变为「预条件输出空间单次」,跨范式必须现测剂量响应。
5. **Σ_o 须摊销形态**:离线拟合 o→Σ_o 映射(按任务/状态聚类的常数块对角)或退化为 λI;在线估计 q_o 协方差需运行时生成器采样,违反 1-NFE。

## 7. 备选与排除

- (a) **2-NFE 种子 kick**:ε′=ε−η∇_ε[C∘f_o](=ε−ηJᵀ∇C),â=f(ε′)——更贴定理 1 的种子倾斜、输出保持在生成器像集内;预算允许时首选对照。
- (b) **离线种子传输**:训练期学 T_o(蒸馏种子 Langevin 流),测试期 ε′=T_o(ε) 后一次前向——定理 4 的种子侧变体,同为训练期摊销。
- (c) 种子 Langevin(K+1 NFE)与 best-of-N 见命题 2 / 推论(iv)。

**1-NFE 硬约束下的使用时方案 = 定理 3;训练期摊销方案 = 定理 4(b 为变体)。**
