## 1. Cup stacking 套杯(SIME 真机原任务)

### 1.1 任务在做什么
把**红色塑料杯**(薄壁,轻、软、易瘪)抓起并**套入金属杯**内。两个杯子的初始位置**每次评测随机摆放**在台面区域内。难点:①薄壁塑料杯抓取力度——夹太紧压瘪、太松滑落(SIME 为此换 TPU 软指);②深腔放置——金属杯口窄于塑料杯张开后轮廓,要对准且下放时不能磕杯沿弹飞;③两杯位置随机 → 初始态异质,天然适配 rescue/pass@10 口径。

- 原始平台:Flexiv Rizon + Robotiq 2F-85(TPU 软指)+ 双 D435i(腕+侧),50 条人遥操作 demo。
- SIME 数字:π0(仅 demo)= **0.34**;naive 自提升 = 0.48;SIME = **0.74**(10 初始态 ×5 次)。
- 论文观察(Fig.6):探索后策略对同一初始态出现**多模态抓取**(左抓/右抓)——与我们"引导产生 DP 不会做的动作"叙事直接呼应。

### 1.2 成功判定
塑料杯**口部完全进入金属杯内且直立不倒**。侧相机判定即可;可选金属杯内底微动开关/导电箔自动化。

### 1.3 评测协议(与仿真对齐)
初始态:台面标定区(建议 20×20cm,AprilTag 定原点)内预生成扰动网格;我们用 **20–30 态 ×10 次**(rescue×10 口径)。轮次:explore→回灌→retrain DP+dyn→再 eval,2–3 轮。

### 1.4 难度旋钮
两杯间距/朝向随机幅度、金属杯与塑料杯的壁间隙(核心参数,**5–10mm**:太大没难度、太小楔死)、demo 数量(50 起步,base>0.5 就减)。

## 2. Mug hanging 挂杯(SOE 真机原任务,主战场)

### 2.1 任务在做什么
抓起**带把手的马克杯**,把**杯柄挂到挂钩架的钩子上**,松手后杯悬空挂着。难点:①挂入动作是"先对准、再平移穿入、再下放脱离夹爪"的窄容差接触序列;②base DP 的习惯性失败 = 从固定方向/高度靠近钩子,差 1–2cm 就撞钩或柄没入钩;③松手瞬间重心转移,没挂稳就掉。是"定向锥"最典型的展示场景。

- 原始平台:Flexiv Rizon4 + Robotiq 2F-85(TPU 软指)+ 双 D435i + sigma.7;动作 10D 相对 EE 位姿 @10Hz,chunk H=20;观测 216×288×3 双相机。
- **50 条 demo**(SOE 认为三任务里最复杂)。
- SOE 数字:Mug Hang 相对提升 **+19.1%**(用户引导转向 +40.4%)——远未饱和,有对比空间。

### 2.2 成功判定
释放后**杯柄挂在钩上、杯体悬空稳定 ≥3 秒**。侧相机判定;架上贴 AprilTag 可精确判位。失败样本归类(撞钩/没挂入/挂后掉落)。

### 2.3 评测协议
初始态 = 杯在台面随机区域(±10cm 网格)+ 柄朝向随机;钩位固定。20–30 初始态 × 10 次重试。

### 2.4 难度旋钮
钩径与杯柄孔的间隙(紧=难)、杯初始位姿/朝向随机幅度、demo 数(50 起步)。

### 2.5 采购清单

| 挂钩架 | 立式/桌沿夹持式,2–4 钩;**钩弯内径 4–6cm、突出 5–7cm、钩间距 ≥15cm**;底座配重 ≥2kg | 1 | 30–80(铁艺)或 ~50(3D 打印+型材) | "铁艺杯架 挂钩 排钩"/"S钩 不锈钢" |

## 3. Drawer opening 开抽屉(AutoSERL / HIL-SERL 系,非 SOE/SIME)

> 第三任务要求:别人做过、非 SOE/SIME、精度可控(吸取 USB 教训)。开抽屉 = 接触丰富 + 容差厘米级 + 成功判定全自动,三者同时满足。

### 3.1 任务在做什么
机械臂**钩住抽屉的环形把手,向外拉开**,抽屉位移 ≥5cm 且保持到 episode 结束算成功(AutoSERL 的原始成功判据)。难点:①钩把手 = 挂系对准(厘米级容差);②**拉的过程中抽屉在动,接触必须跟着走**——持续接触力维持,是套杯(准静态放置)和挂杯(单次挂入)都没有的新维度;③base DP 的习惯性失败 = 挂偏/挂空、拉的角度不对导致脱钩、拉到一半松接触——方向性明确。

- **谁做过**:AutoSERL([arXiv:2607.01651](https://arxiv.org/html/2607.01651v1))抽屉任务原文:"先钩住把手,再向外拉;初始钩-把手距离 ≈10cm;位移 5cm 即成功"(UR5+灵巧手平台);HIL-SERL([arXiv:2410.21845](https://arxiv.org/abs/2410.21845),Science Robotics)的 laptop lid opening 同属铰链/关节体接触家族(Franka)。先例充分且成功判据客观。
- **精度对照 USB**:钩把手 ±1cm 级、拉动无对准要求——比 USB 的 ±0.6°/毫米级宽一到两个数量级,不存在亚毫米瓶颈。
- 差异化卖点:持续接触力任务正是"我们动作有界 + 零硬件梯度 vs HIL-SERL 1–2 小时人在环 RL"的展示面。

### 3.2 成功判定(全自动)
抽屉面板贴 AprilTag,侧相机测位移;**位移 ≥5cm 且保持** = 成功。零人工、二值、与 rescue/pass@10 记账直接兼容。

### 3.3 评测协议与难度旋钮
初始态 = EE 起点位姿网格(钩把手距离 10–20cm,AutoSERL 用 ~10cm)+ 朝向小扰动;demo 数调 base。抽屉导轨阻尼可加配重改变(难度旋钮)。**安全**:Flexiv 碰撞检测/力阈值调低;柜体必须固定(G 夹+配重),防拉翻。Reset = 推回(秒级)。
工程要点:把手选**环形/D 形拉环**(可钩挂);若买到的柜子把手不可钩,自己加一个金属 D 环(~¥5)。拉的阶段用低刚度/慢速位置控制,力由接触自然产生。

## 4. 启动顺序(工程风险递增)

1. **Cup stacking**:无接触风险、判定最简、耗材最便宜 → 先跑通"遥操作采 demo → DP 训练 → 真机推理 → rescue×10 记账 → 回灌 → retrain → 再 eval"整条链,并用 demo 数把 base 标定进甜点带(SIME 参考值 0.34@50 demos)。
2. **Mug hanging**:自制钩排到位后上;主战场,SOE 同任务(+19.1%)。
3. **Drawer opening**:接触力新轴收官;柜体固定与力阈值先行,容差厘米级无精度风险。

**共同前置(开工第一周)**:①确认平台/夹爪/相机/遥操作复用清单;②Camera 标定 + AprilTag 工作区原点;③初始态扰动网格生成器(与仿真 `np.random.seed(42+i)` 同构);④rescue×10 记账字段对齐仿真 json(success_rate / pass@10 / jerk)。
