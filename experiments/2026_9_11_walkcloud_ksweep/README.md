## 判读

1. **基线复刻逐窗一致**（7+11 = 7+11 = 18）→ 协议零漂移，本批配对比较有效。
2. **κ 平**：2.5→5→7.5 读数 18/18/17（二项噪声内）。上一轮"square 上 cap 未咬合"
   （mean_S ≪ κ）的推断由实验直接证实——抬 κ 无效果可调。
3. **gst 平且剂量不变**：gst 100→50 后 mean_inject 从 ~0.40-0.68 掉到 0.014-0.017
   （~48×），hist_len 50.5→25.5，读数纹丝不动（18）。
4. **总 invariant 带**：mean_inject 0.014 → 0.935（~67× 力度范围）内 rescued 恒为
   17-18 → **wc 在 square 上的救回数对自身力度不敏感 = 引导项惰性**；18 更可能就是
   重试噪声（DDPM 5 次重采）给的底（严格说 placebo 未在本冻结集上实测，系推断）。
5. **无一配置 >23** → 预授权分支 (A)（can+th 复测）不触发；κ 无方向、gst 已见平 →
   分支 (B) 的"趋势明确"条件不成立，按纪律交表等用户。
6. **η(scale) 的先验**：η1.5/6.0 只在已测 67× 不变带内再缩 ~0.5-2×；唯 η≈6（注入
   ~1.9）能首次摸到 aty 的位移带（1.5-1.65）——但跨 67× 平坦后恰在 1-2 窗口起
   阈值的可能性极低。τ̃/hist_max（抬 S 的另两个未扫旋钮）同理受剂量不变性压制。
